# D-Team website

Statische one-pager voor het D-Team. Geen build, geen dependencies: `index.html` is de hele site.

## Lokaal bekijken

Open `index.html` in de browser, of:

    npx serve .

## Deployen

Gekoppeld aan Vercel. Elke push naar `main` deployt automatisch.
Framework preset: **Other** - Build command: leeg - Output directory: `.`
